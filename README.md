# CBA Suites Madeira · версія з 3D-туром

Додатковий варіант сайту (основний — репозиторій `cba-suites-madeira`, його не змінено).

## Що нового
- `tour.html` — 3D-прогулянка готелем зі **справжніх фото**: лобі → більярдна → люкс з видом (вітальня, кухня, тераса, вид на Фуншал, спальня) → студія → дуплекс → мансарда → басейн на даху. 17 сцен.
- Кожне фото має свою карту глибини (`assets/depth/`), тому камера рухається всередині фото з реальним об'ємом: мишка / нахил телефона / пальцем — роззирнутися; білі точки — перейти в іншу кімнату; «Провести мене» — автоматична прогулянка.
- На головній — пункт меню «3D-тур» і блок-запрошення після розділу «Номери».
- Мови: EN / PT / UA (як на основному сайті).
